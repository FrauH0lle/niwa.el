# Surface missing information rather than adding a routine handoff footer

When a missing fact could materially change the answer, surface the gap instead of quietly reasoning from a guess. Ask for the fact when it is needed to proceed reliably. The user singled out the missing-information prompt because it catches answers that would otherwise rest on guesses.

For handoffs, the user approved an **opt-in traffic-light format** and was less interested in a recurring `80/20` footer. Do not turn either into a default ending for ordinary replies. This was a preference about useful handoff signals, not a prohibition on discussing an 80/20 tradeoff when it is relevant.
