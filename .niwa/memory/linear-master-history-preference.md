# Ask before moving master

Ask before moving `master` itself. Having a branch ready to land does not constitute approval to move `master`.

Use [Merges and history](docs/commits.md#merges-and-history) for the maintained landing procedure. It covers both `master` and private integration branches and supersedes this topic's earlier allowance for ticket-level merge commits on private integration branches.
